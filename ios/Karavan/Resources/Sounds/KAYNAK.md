# Arayüz ses efektleri

Kaynak: [Kenney Interface Sounds 1.0](https://kenney.nl/assets/interface-sounds)
Lisans: Creative Commons Zero (CC0) — kişisel, eğitsel ve ticari kullanımda serbest,
atıf zorunlu değil. Kenney'e destek olmak için yine de burada anılıyor.

Dosyalar mono, 44.1 kHz, 16-bit WAV'a dönüştürüldü. Özgün karşılıkları:

| Dosya | Kenney kaynağı | Kullanım |
|---|---|---|
| `lv-correct.wav` | `confirmation_001.ogg` | Doğru cevap |
| `lv-wrong.wav` | `error_002.ogg` | Yanlış cevap |
| `lv-complete.wav` | `select_006.ogg` | Ders bitişi |
| `lv-xp.wav` | `tick_002.ogg` | XP sayacı tıkı |
| `lv-heart.wav` | `minimize_006.ogg` | Can kaybı |
| `lv-streak.wav` | `maximize_006.ogg` | Seri uzadı |
| `lv-tap.wav` | `click_002.ogg` | Dokunuş |
| `lv-combo.wav` | `pluck_002.ogg` | Kombo |

Bir sesi değiştirmek için aynı adla yenisini koymak yeterli; kodda değişiklik gerekmez.
